# BMI-sheets
Business model innovation related repo

## Overview
This repository contains tools for generating comprehensive Business Model Innovation (BMI) worksheets. The generated Excel file provides a structured framework for analyzing and planning business model innovations.

## Generated Output
- **business-model-innovation.xlsx**: A comprehensive Excel workbook with four sheets:
  1. **BMI Overview**: Introduction and usage instructions
  2. **Business Model Canvas**: Complete business model mapping framework
  3. **Innovation Framework**: Innovation opportunities analysis
  4. **Analysis & Metrics**: KPIs and risk assessment tools

## Usage

### Prerequisites
- Python 3.6 or higher
- pip package manager

### Installation
```bash
pip install -r requirements.txt
```

### Generate the Excel Sheet
```bash
python3 generate_bmi_sheet.py
```

This will create a `business-model-innovation.xlsx` file in the current directory.

## Features
- Professional styling and formatting
- Structured business model canvas
- Innovation opportunity tracking
- Risk assessment framework
- KPI monitoring templates
- Ready-to-use templates and placeholders

## Release Integration
The generated `business-model-innovation.xlsx` file is tracked in git and will be included in repository releases, providing users with the latest version of the business model innovation framework.
